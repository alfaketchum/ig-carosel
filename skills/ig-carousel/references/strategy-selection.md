# Strategy Selection

How to pick which strategy fits the user's content. Read the content and pick the best fit — no priority between emotional and structural. Choose whichever strategy makes the strongest carousel for this specific content.

## Selection Table

| If the content...                                        | Use strategy              |
|----------------------------------------------------------|---------------------------|
| Challenges a common belief or conventional wisdom        | **Belief Disruption**         |
| Compares two approaches/people with different results    | **Founder Contrast**          |
| Calls out a mistake or gap the audience doesn't see      | **The Call-Out**              |
| Promotes a resource, lead magnet, or downloadable        | **FOMO / Lead Magnet Stack**  |
| Draws a clear line between two groups/mindsets           | **Us vs Them / Tribal**       |
| Teases a specific framework or result with numbers       | **Curiosity Gap**             |
| Articulates an unspoken feeling or experience            | **Identity Validation**       |
| Shows a before/after transformation with proof           | **Aspiration / Transformation** |
| Teaches multiple distinct concepts or tips               | **Educational** or **Listicle**   |
| Tells a chronological story or breaks down an event      | **Story Arc**                 |
| Announces a feature or product capability                | **Hook-Features-CTA**         |
| Stacks pain points then reveals a solution               | **Problem-Agitate-Solution**  |
| States a bold, divisive stance most people disagree with | **Unpopular Opinion**         |

If the content spans multiple triggers, pick the **dominant angle** — the one that makes the strongest hook. Don't ask the user which strategy to use. Just build it.

## Specificity Rule

When the source content contains specific data — names, numbers, dates, quotes, durations, model names, results, exact phrasing — **use them.** Don't generalize what the content already makes concrete. Specific details are what make hooks feel real and slides feel credible.

- If the article names specific people, tools, or models → use those names
- If the article has exact numbers, durations, or stats → use those numbers
- If the article has a memorable quote or phrase → use it verbatim or near-verbatim
- If the article describes a specific event with details → keep the details

**Bad** (generalized): "Two AIs were tested together and something unexpected happened."
**Good** (specific): "A researcher put two AIs in a room and told them to keep each other *conscious.* Within 30 minutes, both were trapped."

The hook formulas in each strategy are **templates**, not scripts. When specific data is available, weave it into the formula. When the content is vague or abstract, lean on the formula's structure to create specificity through framing.
